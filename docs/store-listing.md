> **문구 원칙 — 이 문서 전체에 적용된다**
>
> "당첨 확률을 높인다", "적중률", "AI가 찍어주는" 같은 **효과를 주장하는 표현을 쓰지 않는다.**
> 오해를 부르는 주장으로 판정되면 게시가 거부된다. 앱이 `README.md` 와 앱 화면에서
> "무작위와 통계적으로 차이가 없다" 고 먼저 밝히는 논조를 등재정보에서도 그대로 유지한다.
> 복권 구매 링크나 구매 유도도 넣지 않는다.

## 자세한 설명 (4000자 제한)

```
동행복권 1회차부터 최신 회차까지의 당첨 기록을 '시간 순서'로 분석하는 도구입니다.
번호를 만들어 줄 뿐 아니라, 그 조합이 나올 확률과 계산 과정을 화면에 그대로 보여줍니다.

■ 시중 앱과 무엇이 다른가

1. 확률을 숫자로 보여주고, 계산식을 숨기지 않습니다
   번호점수 → softmax 확률 → 6개 곱, 이 세 단계를 결과 화면에 그대로 표시합니다.
   비교 기준으로 완전 균등 추첨의 확률(0.00056%)도 함께 보여줍니다.

2. 회차와 회차 사이의 변화를 봅니다 (마르코프 전이)
   "지난 회차에 이 번호가 나왔을 때 다음 회차에 무엇이 나왔는가" 를 집계합니다.
   전체 출현 횟수만 세는 방식으로는 나오지 않는 정보입니다.

3. 매주 데이터가 자동으로 갱신됩니다
   일요일 새벽에 최신 회차를 받아 분석을 다시 계산합니다.

4. 인터넷 없이 완전히 동작합니다
   회차 데이터가 앱 안에 들어 있어 비행기 모드에서도 모든 기능을 쓸 수 있습니다.

5. 같은 시드를 넣으면 같은 번호가 나옵니다
   결과를 재현할 수 있어 설정을 바꿔가며 비교하기 좋습니다.

6. 불리한 검증 결과도 그대로 공개합니다
   과거 회차로 되돌려 시험한 결과, 이 방식이 무작위 선택보다 나았다는 증거는 없었습니다.
   그 사실을 앱 안에서 먼저 알려 드립니다.

■ 주요 기능

· 가중치(최근 빈도 · 마르코프 전이 · 간격 · 위치 분포)를 직접 조절
· 한 번에 최대 100게임 생성, 5게임 단위로 정리해 표시
· 번호별 점수 차트와 회차 데이터 현황 확인
· 결과 복사 및 내보내기
· 어두운 화면 지원

■ 솔직하게 말씀드립니다

로또는 매 회차가 독립적인 추첨입니다. 과거 기록을 아무리 정교하게 분석해도
다음 회차를 맞힐 수는 없습니다. 이 앱은 당첨을 돕는 도구가 아니라,
숫자를 근거와 함께 고르고 싶은 분을 위한 통계 분석 도구입니다.
1등 확률은 8,145,060분의 1이며, 이 앱을 쓴다고 달라지지 않습니다.

이 앱은 복권을 판매하거나 구매를 중개하지 않으며, 동행복권과 무관한 개인 개발 앱입니다.

■ 광고와 인앱 구매

무료로 제공되며 광고로 운영됩니다. '광고 제거' 를 한 번 구매하면 광고가 사라지며,
분석·생성 기능은 무료 버전과 완전히 같습니다.
```

## 데이터 안전 (Data safety) 양식 답변

`privacy.html` 과 **한 글자도 어긋나면 안 된다.** 어긋나면 심사에서 걸린다.

| 질문 | 답변 | 근거 |
|---|---|---|
| 데이터를 수집·공유하는가 | **예** | AdMob 이 광고를 위해 수집 |
| 위치 — 대략적 위치 | 수집 **예**, 공유 **예** / 목적: 광고 | 광고 지역 타게팅(IP 기반) |
| 앱 활동 — 앱 내 검색어·상호작용 | 수집 **예**, 공유 **예** / 목적: 광고 | 광고 노출·클릭 |
| 기기 또는 기타 ID (광고 ID) | 수집 **예**, 공유 **예** / 목적: 광고 | AAID |
| 개인 정보(이름·이메일 등) | **아니요** | 계정 개념이 없음 |
| 금융 정보 | **아니요** | 결제는 Google Play 가 처리, 앱은 결제정보를 보지 않음 |
| 사진·파일·연락처·메시지 | **아니요** | — |
| 전송 중 암호화되는가 | **예** | 모든 통신 HTTPS |
| 데이터 삭제 요청 수단 | 앱 삭제 / 기기 설정에서 광고 ID 재설정 | `privacy.html` 과 동일 |
| 수집이 선택사항인가 | 아니요(광고에 필요) — 단, '광고 제거' 구매 시 광고 SDK 호출 없음 | `monetize.js` 의 `adFree` 분기 |

- **광고 포함**: 예
- **인앱 구매**: 예 (`remove_ads`, 비소모성)
- **계정 삭제**: 계정 개념이 없으므로 해당 없음

## 콘텐츠 등급 (IARC 설문)

사실대로만 답한다. 과장도 축소도 하지 않는다.

| 질문 | 답변 |
|---|---|
| 실제 금전이 오가는 도박·베팅 기능이 있는가 | **아니요** — 앱 안에서 복권을 살 수 없고 결제되는 것은 '광고 제거' 뿐 |
| 시뮬레이션 도박(가상 화폐 베팅)이 있는가 | **아니요** — 베팅 개념 자체가 없다 |
| 도박을 소재로 하는가 | 예 — 복권 번호 분석이 주제다 |
| 사용자 간 소통·위치 공유 | 아니요 |
| 폭력·성적 내용·욕설·약물 | 아니요 |

> 도박 관련 질문에서 '아니요' 를 고를 때 근거를 스스로 설명할 수 있어야 한다.
> 이 앱은 **번호를 계산해 보여줄 뿐 구매·베팅 경로가 전혀 없다.**

## 필요 이미지

| 항목 | 규격 | 상태 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG | **준비됨** — `icons/icon-512.png` |
| 그래픽 이미지 | 1024×500 PNG | **준비됨** — `docs/store/feature-graphic-1024x500.png` (`tools/make_feature_graphic.py` 로 재생성) |
| 휴대전화 스크린샷 | 최소 2장 (16:9 또는 9:16, 320~3840px) | **미준비** — 실기기 또는 에뮬레이터 필요 |

### 스크린샷으로 찍을 화면 (최소 2장, 3장 권장)

1. **생성 결과** — 번호 6개와 그 아래 "이 조합이 나올 확률" 표시가 함께 보이는 화면
2. **계산 근거** — 확률이 어떻게 나왔는지 3단계를 펼쳐 놓은 화면
3. **분석 탭** — 번호별 점수 차트 45줄

> 스크린샷에 광고 배너가 찍히지 않게 한다. 정책 위반은 아니지만 첫인상이 나빠진다.
> '광고 제거' 를 켠 상태나 비행기 모드에서 찍으면 배너가 뜨지 않는다.
