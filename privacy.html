개인정보처리방침

로또 번호 분석기 · 시행일 2026년 9월 13일

본 방침은 안드로이드 앱과 웹 버전 ‘로또 번호 분석기’(이하 ‘앱’)에 모두 적용됩니다. 앱은 개인 개발자가 만든 통계 분석 도구이며, 별도의 회원 가입이나 계정이 없습니다.

1. 개발자가 직접 수집하는 정보 — 없음

개발자는 자체 서버를 운영하지 않습니다. 따라서 다음 정보를 수집하지도, 전송받지도, 보관하지도 않습니다.

  • 이름·이메일·전화번호 등 신원 정보
  • 위치 정보, 연락처, 사진, 파일, 통화 기록
  • 사용자가 생성한 번호 조합과 설정값

사용자가 앱에서 만든 번호, 시드, 가중치 설정, 회차 데이터는 기기 안의 브라우저 저장소 (localStorage)에만 저장되며 기기를 떠나지 않습니다.

2. 광고를 위해 제3자가 수집하는 정보

앱은 무료로 제공되며 Google AdMob 광고로 운영됩니다. AdMob은 광고를 게재하고 성과를 측정하기 위해 다음을 수집할 수 있습니다.

항목목적

이 정보는 Google이 직접 수집하고 처리하며 개발자는 개별 사용자를 식별할 수 있는 형태로 열람하지 않습니다. 개발자가 보는 것은 합계 통계(노출 수, 예상 수익 등)뿐입니다.

자세한 내용은 Google이 파트너 사이트·앱에서 정보를 사용하는 방식을 참고하세요.

3. 결제 정보

앱 안에서 ‘광고 제거’를 구매하는 경우, 결제는 전적으로 Google Play가 처리합니다. 카드 번호를 비롯한 어떤 결제 수단 정보도 앱과 개발자에게 전달되지 않습니다. 앱은 ‘구매했는지 여부’만 확인해 광고 표시를 끕니다.

4. 회차 데이터 갱신 시의 통신

앱에는 과거 당첨 회차 데이터가 동봉되어 있어 인터넷 없이도 모든 기능이 동작합니다. 사용자가 설정에서 ‘최신 회차 가져오기’를 직접 누른 경우에만 공개 데이터 엔드포인트에 접속하며, 이때 전송되는 것은 요청한 회차 번호뿐입니다. 개인정보는 포함되지 않습니다.

5. API 키 취급

키가 필요한 엔드포인트를 쓰는 사용자를 위해 설정에 API 키 입력란이 있습니다. 앱은 다음을 지킵니다.

  • 키는 이 기기의 저장소에만 보관하며 개발자 서버로 전송하지 않습니다.
  • 전송이 필요할 때는 URL이 아닌 HTTP 헤더로만 보냅니다. (URL에 넣으면 브라우저 기록·중계 서버 로그·Referer 헤더에 평문으로 남습니다.)
  • 키를 콘솔에 출력하지 않고, 번호 복사·내보내기에도 포함하지 않습니다.
  • 화면에는 항상 마스킹해 표시합니다.

6. 아동 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

7. 사용자의 선택권

  • 맞춤 광고 끄기 — 안드로이드 설정 → Google → 광고에서 ‘광고 ID 삭제’ 또는 ‘맞춤 광고 선택 해제’를 설정할 수 있습니다.
  • 광고 완전 제거 — 앱 내 ‘광고 제거’를 구매하면 광고 SDK를 호출하지 않습니다.
  • 저장된 데이터 삭제 — 앱을 삭제하거나, 안드로이드 설정 → 앱 → 저장공간 → 데이터 삭제를 누르면 기기에 저장된 모든 값이 지워집니다. 웹 버전은 브라우저의 사이트 데이터 삭제로 같은 효과를 냅니다.

8. 보안

앱은 서버로 개인정보를 보내지 않으므로 전송 중 유출 위험이 구조적으로 없습니다. 다만 기기의 브라우저 저장소는 암호화되지 않습니다. 공용 기기에서 사용했다면 사용 후 데이터를 삭제하시기 바랍니다.

9. 방침 변경

내용이 바뀌면 이 페이지를 갱신하고 상단의 시행일을 수정합니다. 중요한 변경은 앱 업데이트 설명에도 함께 안내합니다.
